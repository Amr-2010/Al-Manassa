# Implementation roadmap
1. Identity: ASP.NET Core Identity, role-based authorization, admin provisioning and audit logging.
2. PostgreSQL via EF Core migrations, real course CRUD, enrollments and lessons.
3. Protected video storage and uploads, course progress, quizzes and certificates.
4. Blazor admin, instructor and learner dashboards; full Arabic/English localization.
5. MAUI client API integration and secure token storage; Android/Windows/iOS UX.
6. Payment gateway integration, live classes, notifications and analytics.
7. Automated tests, CI/CD, Android APK, Windows installer and signed iOS IPA.

Do not deploy the sample endpoints as a production LMS without authentication, authorization and operational security.
